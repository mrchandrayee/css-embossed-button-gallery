CSS Embossed Button

1. Classic Embossed Button

CSS CODE

.btn1:hover {
  transform:
    translateY(-3px);
  box-shadow:
    -10px -10px 20px #ffffff,
    10px 10px 20px #94a3b8;
}

2. Pressed Embossed Button

CSS CODE

.btn2:hover {
  box-shadow:
    inset -10px -10px 18px #fff,
    inset 10px 10px 18px #94a3b8;
}

3. Neon Embossed Button

CSS CODE

.btn3:hover {
  background: #38bdf8;
  color: #0f172a;
  box-shadow: 0 0 30px #38bdf8;
  transform: translateY(-2px);
}

4. Gradient Embossed Button

CSS CODE

.btn4:hover {
  transform:
    translateY(-3px) scale(1.02);
  box-shadow:
    0 15px 25px
    rgba(236, 72, 153, .5);
}

5. Metallic Embossed Button

CSS CODE

.btn5:hover {
  filter: brightness(1.05);
  transform: translateY(-2px);
}

6. 3D Embossed Button

CSS CODE

.btn6:hover {
  transform: translateY(-2px);
  box-shadow:
    0 8px 0 #4338ca,
    0 15px 25px
    rgba(99, 102, 241, .5);
}

7. Circular Embossed Button

CSS CODE

.btn7:hover {
  transform: rotate(90deg)

}

8. Glass Embossed Button

CSS CODE

.btn8:hover {

    rgba(255, 255, 255, 0.3);

}

9. Dark Embossed Button

CSS CODE
